Usage Example: Merging Duplicate Entities

In this mockup, we have 3 entities selected that appear to be the same character (Aldric) appearing in different sources:

  • "Aldric the Wise" from eldoria_characters.txt
  • "Aldric" from eldoria_story.txt
  • "Aldric the Archmage" from eldoria_lore.txt

The admin can:

  1. Select all three entities using the checkboxes
  2. Click the "Merge Selected (3)" button
  3. Choose the canonical name (e.g., "Aldric the Wise")
  4. The system will merge all three into one entity, combining their descriptions, adding variant names as aliases, and consolidating all relationships

Note: The merge function currently merges 2 entities at a time, so for 3 entities, it would need to be called twice. Future enhancement could support multi-entity merge in one operation.
