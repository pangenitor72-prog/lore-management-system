# AIRpg Vision## What AIRpg IsAIRpg is an AI-powered roleplaying engine that transforms a creator’s existingcampaign lore into an infinite, living storytelling experience.It is not a rules simulator.It is not a text adventure generator.It is not a generic AI DM.AIRpg is a world interpreter that:- Preserves the creator’s voice- Maintains consistent personalities- Allows the world to evolve when unobserved- Lets players discover outcomes rather than receive summaries## The Core ProblemMost AI RPGs fail because they:- Forget who characters are- Break tone and personality- Generate disconnected scenes- Simulate everything or nothingAIRpg solves this by separating:- Facts from voice- Canon from session outcomes- World logic from presentation## The SolutionAIRpg uses:- A graph database for facts, relationships, and state- A vector database for prose, voice, and atmosphere- A mandatory personality system (OCEAN)- Lazy world simulation (Decoherence Engine)The result is a world that feels alive without being exhaustively simulated.## Success DefinitionAIRpg succeeds if:- Players recognize NPCs without being told their names- NPC behavior remains consistent over long play sessions- The world changes plausibly when the player is absent- The creator’s original prose is preserved, not summarizedAIRpg values believability over completeness.
