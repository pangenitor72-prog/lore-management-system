# AIRpg Architecture## System OverviewLore → Ingestion → Dual Databases → Game Engine → PlayerAIRpg is a layered system with strict responsibility boundaries.## Core Components### 1. Lore Ingestion- Parses structured markdown- Extracts entities and relationships- Stores facts in Neo4j- Stores prose in vector collections- Generates OCEAN profiles### 2. Dual Database ModelNeo4j (Facts):- Entities- Relationships- State- TimelinesVector DB (Voice):- Descriptions- Cultural texture- Atmospheric prose- NPC mannerismsThese databases are queried together but never merged.### 3. Game Engine- Scene Generator (DM)- Character Engine (NPC behavior)- Story Thread Engine- Decoherence Engine (time & consequence)### 4. API Layer- Campaign management- Scene progression- Lore ingestion- Session isolation## Design Pattern Commitments- Event-driven- Lazy evaluation- Prompt layering- Session isolation
