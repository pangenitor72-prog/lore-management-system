# AIRpg Design PrinciplesThese principles are non-negotiable.## 1. Preserve the Creator’s Voice- Original prose is stored verbatim- AI uses examples, not summaries- Lore is never rewritten or “improved”## 2. OCEAN Is Mandatory- Every NPC has an OCEAN personality profile- All NPC behavior must reflect those traits- Personality drives action, dialogue, and reaction## 3. Sacred vs Session Canon- Seed lore is immutable- Generated events belong to a single campaign- No session can alter sacred canon## 4. Show, Don’t Tell- Generate scenes, not summaries- Players discover consequences- Avoid omniscient narration## 5. Player Intent ≠ World Outcome- Players express intent, not control- The world decides outcomes- Waiting, traveling, and inaction have consequences## 6. Lazy Evaluation- The world is not continuously simulated- Changes are resolved when observed- Believability matters more than precision## 7. Memory Is Permanent- Facts are stored in the graph- Moments are stored in vectors- NPCs remember what happened## What We Explicitly Avoid- Generic NPC dialogue- Arbitrary difficulty scaling- Personality drift- Railroading- Retconning canon
